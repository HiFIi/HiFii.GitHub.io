How to Contribute Translations

Thank you for your interest in contributing to ThunderDex translations! Follow these steps to get started:

1. Set up your GitHub Profile

If you don't have a GitHub account, you'll need to create one. It's free and easy! Once you have an account, you can personalize your profile by adding a profile README to showcase your skills and projects. [7, 8, 9, 11, 12]

  • Go to github.com/join to create a new account.
  • Consider creating a special repository named after your GitHub username (e.g., `your-username/your-username`) to create a profile README. [8, 9, 11] This allows you to add an "About Me" section to your profile. [8]

2. Fork the Translation Repository

Forking a repository creates a personal copy of the project in your GitHub account. This allows you to make changes without affecting the original project. [2, 3, 4, 6]

  • Go to the WarThunderWiki-Translations repository.
  • In the top-right corner of the page, click the "Fork" button. [2, 3, 4]
  • A copy of the repository will be created under your GitHub account (e.g., `your-username/WarThunderWiki-Translations`). [2, 4]

3. Understand the Translation Folders

The translation files are typically located in the `strings.xml` file within language-specific folders. [16, 17]

  • The main translation file you'll be working with is `strings.xml`.
  • Each language will ideally have its own folder structure (e.g., `values-xx/strings.xml` where `xx` is the language code). For example, `values-ru` for Russian, `values-de` for German.
  • You'll primarily be modifying the values within the `strings.xml` file for your chosen language.

After making your changes to the `strings.xml` file in your forked repository, you can then create a "Pull Request" to submit your translations back to the original project. This allows the project maintainers to review and merge your contributions. [5]
