Contribute Translations / Open Source

Thank you for your interest in contributing to ThunderDex translations! Follow these steps to get started:

1. Set up your GitHub Profile

If you don't have a GitHub account, you'll need to create one. Once you have an account, you can personalize your profile.

  • Go to github.com/join to create a new account.

2. Fork the Translation Repository

Forking a repository creates a personal copy of the project in your GitHub account. This allows you to make changes without affecting the original project.

  • Go to the WarThunderWiki-Translations repository and click the "Fork" button.

3. Understand the Translation Files

The translation files are located in `strings.xml` within language-specific folders (e.g., `values-ru` for Russian). After making changes, create a "Pull Request" to submit your translations.

For the main application source code, visit the ThunderHub GitHub repository.
