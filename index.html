🚀 Contribute Translations to ThunderDex

Want to help localize ThunderDex into your language? Follow this quick guide to learn how to fork the project and submit your first pull request on GitHub.

1. Create Your GitHub Account

Don’t have a GitHub account yet? Sign up below:

  • github.com/join

2. Fork the Translations Repository

This creates your own editable copy of the ThunderDex translations repo:

  • WarThunderWiki-Translations on GitHub

3. Add a Language Folder

Inside the project, translations live in Android-style folders like:

app/src/main/res/values-ru/strings.xml

Make a new folder for your language using the format:

values-xx

Replace xx with your language code, e.g. values-fr for French.

💡 Tip: See README.md for supported language codes and examples.

4. Edit strings.xml

Inside your new folder, create or update the strings.xml file with your translations.

5. Submit a Pull Request

Once your changes are committed to your forked copy, open a pull request back to the original repository:

  • Open a Pull Request

We'll review it and merge your contribution!

6. Want to Contribute Code?

The main source code for the ThunderDex Android app is here:

  • ThunderHub GitHub Repository
